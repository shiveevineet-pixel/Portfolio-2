# 🚀 Premium Interactive Developer Portfolio

A modern, premium, fully responsive developer portfolio built with HTML5, CSS3, JavaScript, Three.js and GSAP.

Designed for developers, freelancers, designers, AI engineers, agencies, and creative professionals who want a stunning online presence.

---

# ✨ Features

- Premium Luxury Design
- Fully Responsive
- HTML5 / CSS3 / JavaScript
- Three.js Interactive Background
- GSAP Smooth Animations
- Scroll Animations
- Premium Hero Section
- About Section
- Skills Showcase
- Services Section
- Projects Gallery
- Experience Timeline
- Contact Form
- Resume Download
- SEO Friendly Structure
- Fast Loading
- Clean & Organized Code
- Easy to Customize

# ✏️ Customization

## Change Name

Open

```
index.html
```

Replace

```
Preet Rajput
```

with your own name.

---

## Change Profile Image

Replace the image inside

```
assets/images/
```

Keep the same filename or update it inside HTML.

---

## Change About Text

Open

```
index.html
```

Search

```
About
```

Replace with your own content.

---

## Change Skills

Edit the Skills section in

```
index.html
```

---

## Change Services

Edit the Services section in

```
index.html
```

---

## Change Projects

Replace:

- Images
- Titles
- Description
- Links

inside the Projects section.

---

## Change Resume

Replace

```
assets/resume.pdf
```

with your own resume.

---

## Change Contact Information

Replace:

- Email
- GitHub
- LinkedIn
- Instagram

inside

```
index.html
```
